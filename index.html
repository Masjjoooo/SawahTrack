Tim dan akses pengguna

Setiap orang menggunakan akun sendiri. Pembuatan akun operator dilakukan oleh admin melalui Supabase Auth, lalu admin menetapkan role.

AdminMengelola semua data, tim, pengaturan dan laporan.
OperatorMencatat pemilik, petakan, pekerjaan dan pengeluaran.
ViewerHanya melihat data dan laporan.

Untuk keamanan, undangan akun dan perubahan role dikelola melalui dashboard Supabase; jangan pernah menaruh service-role key di aplikasi browser.
